# 0010. Authentication

**Status:** accepted · 2026-10-04

Two accounts, created by the seed script from `SEED_*` variables: hers (`/entra`) and the
admin's (`/admin/entra`). Passwords hashed with Node's built-in **scrypt**. Sessions are random
32-byte tokens in httpOnly, SameSite=Lax cookies; the database stores only an HMAC of the token
(`SESSION_SECRET`), so a database leak cannot be replayed. Sessions last **180 days** so she stays
signed in on her phone and laptop. The admin uses a separate cookie, so both can be signed in
on the same device. Every server action re-checks the session (they are reachable by direct POST).
No auth library: fewer moving parts to explain.
