# Credits and licences

## Images

All images in `src/assets/demo/` are original illustrations generated by code in this
repository (`scripts/illustrations/`, run with `npm run illustrazioni`). No stock photos,
no third-party images, no licences to track. Same for the logo, favicons and social images.

The brief asked for Unsplash or Pexels photos; those hosts were blocked from the environment
the site was built in, so the demos use drawn scenes instead. To switch a demo to real photos,
replace the `.jpg` files in `src/assets/demo/{slug}/` keeping the same names (16:10, about
1600 px wide), and list each photo's source URL and photographer here.
