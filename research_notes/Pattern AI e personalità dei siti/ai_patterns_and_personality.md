# Pattern AI e personalità dei siti: the "AI look" tells, why models converge, and how to give each site its own personality

Research date: 22 Nov 2026. Scope: sites produced by LLM coding assistants (Claude, ChatGPT/Codex, v0, Lovable, Bolt, Cursor). Context: a Milan studio building small Italian business sites (pilates, B&B/agriturismo, wedding venues, renovation firms) whose sites "all look the same (same italic, same layout)".

Method note: dev.to and prg.sh were not reachable from this session (network allowlist), so several dev.to articles are cited from search-result summaries only, not read in full. Primary documents read in full: Anthropic's current `frontend-design` SKILL.md (GitHub), Anthropic's blog post of 12 Nov 2025, the `avoid-ai-design` repo README, the Impeccable repo README and PR #129. Everything else comes from search summaries and is marked as such where it matters.

Evidence vs opinion: almost all of this field is practitioner opinion (blogs, tool vendors, skill authors). The only quantitative material found is small samples (120 pages, 72 sites). No large-scale or peer-reviewed analysis of thousands of AI-generated sites was found.

## 1. Which patterns are named as giveaways of AI-generated sites (2024-2026)?

### Takeaway
There are two generations of "AI look". **Generation 1 (2024 to mid-2025)**: Inter/system font, purple-to-blue gradient on white, centred hero with pill badge and two buttons, three icon cards, glassmorphism, shadcn defaults. **Generation 2 (late 2025 to 2026)**, the "tasteful default" that came out of anti-slop prompting itself: cream/off-white background, a thin high-contrast serif display (Instrument Serif, Fraunces, Cormorant, Playfair, Newsreader) with **one italic or coloured accent word in the headline**, terracotta/clay or sage accent, tracked ALL-CAPS eyebrow labels above every heading, `01/02/03` numbering, mono micro-labels, `A · B · C` meta strings, `→` on every link, and hairline-rule "broadsheet" layouts. The studio's "same italic" complaint matches Generation 2 exactly. Anthropic's own skill now lists these as tells.

### Cited Findings

**Anthropic's current official guidance (the strongest primary source; it names the studio's exact problem)**
- Anthropic's `frontend-design` SKILL.md (current version, read Nov 2026) lists as "typographic defaults (tells of a generated page)": "Accenting just a single word or phrase in a headline, like putting one word in italic/bold or a different color"; "Using all caps for labels"; "Adding unnecessary typographic labels above content." — [anthropics/skills frontend-design SKILL.md](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)
- The same file lists "common AI-generated design traits to avoid": (1) "a warm cream background (near #F4F1EA) with a high-contrast serif display and a terracotta or warm-clay accent (often near #D97757 — Anthropic's own Claude-interaction accent, so on a user's brief it reads as a tell)"; (2) "a near-black background with a single bright acid-green or vermilion accent"; (3) "a broadsheet-style layout with hairline rules, zero border-radius, and dense newspaper-like columns"; (4) "the SaaS-card kit: identical rounded cards, one border-radius on everything, the same soft grey shadow (rgba(0,0,0,.1)), gradient washes as decoration"; (5) "template chrome": "a tracked-out ALL-CAPS eyebrow label above every heading; meta strings joined with middle dots ('A · B · C'); labels built as 'WORD — fragment' with a spaced em dash; tinted near-black (#0B0B0B, #111) standing in for black; a monospace face for small data labels; a '→' appended to link and button text." — [anthropics/skills frontend-design SKILL.md](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)
- The file adds that these are legitimate for some briefs and are a problem only when they appear by default whatever the subject; numbering only when content really is a sequence; eyebrows, borders and dividers should "encode information"; a hero made of a big number, a small label, supporting stats and a gradient accent is "the default treatment, so only use it if that's truly the best option." — [anthropics/skills frontend-design SKILL.md](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)
- A DEV Community post (read only as a search summary) says Anthropic rewrote the skill on June 18 and that the new version contradicts the old one on its central thesis. Not verified against an Anthropic changelog, but consistent with the difference between the Nov 2025 blog (below) and the current file. — [DEV: Anthropic rewrote frontend-design skill](https://dev.to/kenimo49/anthropic-rewrote-frontend-design-skill-3-ai-design-cliches-named-with-hex-codes-22m4)

**Generation 1 tells (purple/Inter/SaaS)**
- Anthropic, 12 Nov 2025: an unguided landing page request tends toward "Inter fonts, purple gradients on white backgrounds, and minimal animations." — [Anthropic: Improving frontend design through Skills](https://claude.com/blog/improving-frontend-design-through-skills)

**Generation 2 tells: serif display + one italic word + cream**
- Impeccable PR #129 (opened 30 Apr 2026, merged 2 May 2026) added a detector rule `italic-serif-display`: an h1 (or h2 ≥48px) set in italic serif ≥48px, with a known-serif list that names **Fraunces, Recoleta, Newsreader, Playfair, Cormorant, Tiempos**; the PR calls it a "category-defining tell" of late 2025 / early 2026, while noting "editorial/magazine register may legitimately want the pattern — judge by context." - The Crit (search summary) notes Instrument Serif became common *because* it is the usual recommended "fix" for generic typography. — [The Crit: Vibe coding design guide](https://thecrit.co/resources/vibe-coding-design-guide)
- A 2026 benchmark of Claude design skills (search summary) found the new default is "teal on cream with a serif headline"; Unslop describes a "tasteful default" (cream background, serif display face, sage-green accent) that anti-slop advice itself created. — [AgentSkillsHub: 207 Claude design skills graded](https://agentskillshub.top/best/ai-design/); [Unslop UI: Fonts and colors that avoid the AI look](https://unslopui.org/blog/best-fonts-colors-avoid-ai-look-saas-landing-page)
- Anthropic's own palette reportedly uses clay #d97757 on cream, so part of the look mirrors Anthropic's branding (third-party description). — [shadcn.io: Anthropic design system](https://www.shadcn.io/design/anthropic)

**Eyebrows, pills, chrome**
- Jonathan Schneider (X, 2026): "Most AI-generated landing pages share the same tells: an eyebrow label above every heading, tracked capital labels, one colored word in the headline." — [X: Jonathan Schneider](https://x.com/JonathanSchndr/status/2114694281579708553)
- Paralect lists 21 signs, each with a fix: the eyebrow "usually names the section type; drop it; work it into the heading"; pills reading "NEW/BETA/AI" above titles; coloured dots next to section names; card overuse; bordered sections; uniform corner radii; fade animations; fake proof; glass cards. — [Paralect: Signs of AI slop in design, 21 patterns](https://www.paralect.com/blog/signs-of-ai-slop-in-design)
- Innovatemap notes AI puts labels above *and* below the same title, which weakens hierarchy. — [Innovatemap: 6 signs of AI-generated UI](https://innovatemap.com/resource/signs-of-ai-generated-ui)
- Fake social proof: invented figures such as "10,000+ satisfied customers" and invented testimonials listed as a sign. — [Noqode: AI slop design, 10 signs](https://www.noqode.fr/en/blog/design-ia-generique)

- Counter-view: several writers argue the em dash and the rule of three are legitimate devices and that what gives copy away is "the pile": dashes + a triple + "elevate" + zero specifics. — [J.R. - Anthropic's skill copy rule: write from the end user's view, active voice ("Save changes" not "Submit"), sentence case. — [anthropics/skills frontend-design SKILL.md](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)

### Inferences
- The studio's "same italic" is almost certainly the Generation 2 pattern (serif display + italic accent word + cream), which Claude in particular drifted toward after Generation 1 was widely criticised; the Nov 2025 Anthropic blog itself recommended Playfair, Newsreader, Space Grotesk and Bricolage, and several of those are now on the tell lists (see section 2).
- The poetic three-word imperative tagline ("Respira. Muoviti. Rigenera.") combines two tells, the reflexive triplet and fragment slogans. No source names this exact form, but it follows directly from the "rule of three" and "Not X. Y." slogan entries.
- For Italian small businesses the most damaging tells are the ones that also **invent facts**: "500+ clienti", five-star rows, placeholder testimonials. They are also forbidden by the project's own CLAUDE.md rule against inventing client facts.

### Gaps
- No source specifically names "Breathe. Move. Restore."-style wellness taglines, bento grids, or testimonial carousels as AI tells with evidence. Bento grids came up in no result at all.
- Couldn't read the Hacker News "Ask HN: How can you tell a site/app is vibe coded?" thread in full (host not reachable). The search summary only says commenters cited Inter, heavy gradients, and models "reasoning their way into the same design choices". — [HN 49290499](https://news.ycombinator.com/item?id=49290499); [HN 45622944 (vibe-coded.lol parody)](https://news.ycombinator.com/item?id=45622944)

## 2. Why do models converge? Is it quantified?

### Takeaway
The mechanism Anthropic names is **distributional convergence**: models sample from the high-probability centre of their training data, where safe, universally acceptable designs dominate. It is reinforced by shared component kits (Tailwind/shadcn defaults; v0 is trained on shadcn defaults) and by anti-slop advice that itself becomes the next default (the "next attractor" problem). Quantification is thin: one count of 120 pages and one grading of 72 sites, both informal.

### Cited Findings
- Anthropic (12 Nov 2025): "During sampling, models predict tokens based on statistical patterns in training data." "Safe design choices–those that work universally and offend no one–dominate web training data." "Without direction, Claude samples from this high-probability center." Its prompt tells the model: "You tend to converge toward generic, 'on distribution' outputs." — [Anthropic: Improving frontend design through Skills](https://claude.com/blog/improving-frontend-design-through-skills)
- In the same post Anthropic *recommended* specific fonts: "Never use: Inter, Roboto, Open Sans, Lato, default system fonts"; code: JetBrains Mono, Fira Code, Space Grotesk; editorial: Playfair Display, Crimson Pro; technical: IBM Plex, Source Sans 3; distinctive: Bricolage Grotesque, Newsreader; and "Pick one distinctive font, use it decisively. Load from Google Fonts." — [Anthropic blog, Nov 2025](https://claude.com/blog/improving-frontend-design-through-skills)
- The "next attractor" problem: a critique of Impeccable notes it "avoids Inter, but picks the very next overused font in its training weights"; Bakaus says models are overfitted to "stylistic gravity wells" and bans only move the model to a nearby alternative. — search summaries of [Bakaus talk, AI Engineer](https://ai.engineer/talks/SQMCtZX3trg-dark-arts-skill-engineering-paul-bakaus) and [BigGo write-up](https://finance.biggo.com/news/71cfafb357af64ab)
- Tailwind indigo: on 7 Aug 2025 Tailwind co-creator Adam Wathan posted a half-joking apology for making every Tailwind UI button `bg-indigo-500` five years earlier, linking it to AI UIs defaulting to indigo/purple; exact wording differs across reports, and the training-data feedback loop is commentators' interpretation, not established fact. — [Product Hunt: An accidental choice, a butterfly effect](https://www.producthunt.com/p/vibecoding/an-accidental-choice-a-butterfly-effect-and-the-future-of-ai-aesthetics); [AIbase](https://news.aibase.com/news/20365)
- Component kits: v0 writes Next.js + Tailwind + shadcn/ui and its docs say it is "specifically trained on the default implementations of the shadcn/ui components" (quoted in a DEV write-up; search summary). — [DEV: We graded 72 AI-built sites](https://dev.to/landingpagegods/why-do-ai-generated-websites-all-look-the-same-we-graded-72-2026-300c)
- HN commenters note the look is shared by any site built on the same component libraries and compare it to 2010s Bootstrap/Material startup pages. — [HN 45622944](https://news.ycombinator.com/item?id=45622944)

**Quantitative evidence (all small, informal)**
- Build to Launch (Jenny Ouyang, Substack): counted 16 habits across **120 AI-built pages**. Feature cards with an icon on top in a 3-4 grid appeared on **63% of landing pages**; a single icon set (Lucide) on **63% of all pages**; default shadcn colours on **61%**; **57 of 120 pages showed six or more signs**. The author says no single sign is decisive; the combination is. — [Build to Launch: How to stop your website looking like AI slop](https://buildtolaunch.substack.com/p/fix-ai-slop-website-design)
- Landing Page Gods graded **72 live Lovable/v0/Bolt sites** against 20 well-known SaaS sites: AI-built sites averaged 46/100 vs 72/100 (marketing-adjacent, own rubric). — [DEV: We graded 72](https://dev.to/landingpagegods/why-do-ai-generated-websites-all-look-the-same-we-graded-72-2026-300c)
- Bakaus reports "much more font and color diversity" with his anti-attractor procedure, but in his own internal eval (self-reported), and says his judging sub-agents do "only slightly better than chance" at taste. — [Bakaus on X, Impeccable 2](https://x.com/pbakaus/status/2044505743144194514?lang=en); [BigGo](https://finance.biggo.com/news/71cfafb357af64ab)

### Inferences
- The Nov 2025 Anthropic list ("use Playfair, Newsreader, Space Grotesk, Bricolage...") is a good illustration of how a fix becomes a tell: by mid-2026 Playfair, Newsreader and Space Grotesk all appear on tell lists. **Any fixed list of "good fonts" will converge too** if the same assistant uses it for every client. The studio needs a process that produces different outputs per client, not a better fixed list.
- Note for this project: the Nov 2025 blog says "Load from Google Fonts". That conflicts with the studio's own GDPR rule (only @fontsource, no third-party requests). Every family below is available as a Fontsource package because Fontsource mirrors Google Fonts.

### Gaps
- No large-scale corpus study (thousands of v0/Lovable sites) was found; search explicitly turned up none. No peer-reviewed work on visual mode collapse in code-generating LLMs was found.
- Couldn't verify the original Wathan tweet text.

## 3. Concrete methods for distinct personality per site

### Takeaway
Practitioners converge on one principle: **start from the subject, not a style.** Derive art direction from the business's industry, materials, place and vernacular; decide a written token system (4-6 named colours, 1-2 clearly distinct typefaces with roles, a layout concept as an ASCII wireframe) *before* coding; review it against "would I have done this for any similar page?"; and give each site one memorable signature rather than many effects. Sourced guidance on specific Italian-suited font families is thin, so the named families below are mostly my own recommendations (flagged).

### Cited Findings
- Anthropic: visual choices should come from the subject's "industry, subject matter, materials, and vernacular"; the hero should open with "the most characteristic thing in the subject's world"; use one family or two "clearly distinct" ones; line length under 80 characters; serif body text needs more line-height than sans. Process: (1) compact token system, 4-6 named hex colours, typefaces and roles, layout concept with ASCII wireframes; (2) review the plan against the brief and revise anything generic; (3) build; (4) critique with screenshots, applying Chanel's rule, "before leaving the house… remove one accessory"; "a single orchestrated moment… lands better than scattered effects." — [anthropics/skills frontend-design SKILL.md](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)
- Anthropic (Nov 2025): "Dominant colors with sharp accents outperform timid, evenly-distributed palettes"; "Create atmosphere and depth rather than defaulting to solid colors" with layered gradients, geometric patterns or contextual effects. — [Anthropic blog](https://claude.com/blog/improving-frontend-design-through-skills)
- `avoid-ai-design`: derive 4-6 colours with defined roles "from the product's materials and artifacts"; pick a type direction from the product (display + text face); "let the page's central artifact or product world lead the layout"; test each choice with "would I have done this for any similar page?" — [GitHub: avoid-ai-design](https://github.com/funboy322/avoid-ai-design)
- Anti-attractor (Bakaus/Impeccable 2): force the model to "enumerate and reject its reflex defaults before picking"; seed generation with something the model would not choose itself (from the user or a script, e.g. a hand-curated palette file or a random reference); a variant is asking for the top three fonts and then throwing them away; or generate many options and have a blind sub-agent rank them. Impeccable's process runs `init` to write PRODUCT.md (context interview), `document` → DESIGN.md, `shape` before code, then critique/audit/polish. — [Impeccable README](https://github.com/pbakaus/impeccable); [Bakaus on X](https://x.com/pbakaus/status/2044505743144194514?lang=en); [AI Engineer talk](https://ai.engineer/talks/SQMCtZX3trg-dark-arts-skill-engineering-paul-bakaus)
- Place-based identity (vendor guide): tie the digital identity to the location's landscape, geology and architecture; study traditional local building styles; set clear art direction for local photography. — [Silphium Design: place-based visual identity](https://silphiumdesign.com/brand-consistency-place-based-visual-identity/)
- Signature elements: a repeated motif across every page (their example is corner brackets, suited only to some brands), a custom display face for a single element, or one signature animation; shifting hues 20-40° off the defaults; avoiding pure black/white. — [Sailop: 73 patterns that break the AI default](https://sailop.com/blog/from-ai-slop-to-signature-73-patterns-2026) (vendor blog, opinion)
- Mood boards: write a brief that explains *why* each cue belongs, and ask whether a cue is "distinctive in this category or already overused?" — [LeftHD: AI mood board to branding brief](https://lefthd.com/insights/ai-mood-board-to-branding-brief/)
- Italian type heritage available free: Titillium (Titillium Web) is an Italian participatory project from the Accademia di Belle Arti di Urbino ecosystem (Luciano Perondi; first prototype by Diego Giusti), released under SIL OFL 1.1 and used in Italian public-administration design. — [Designers Italia: Un carattere per l'identità italiana](https://medium.com/designers-italia/un-carattere-per-l-identit%C3%A0-italiana-c704f3e4791d). Bodoni Moda is an OFL revival (by Owen Earl) of Giambattista Bodoni's Parma Didone, with an optical-size axis. — [FontFYI: Bodoni Moda](https://fontfyi.com/font/bodoni-moda/); [Wikipedia: Bodoni](https://en.wikipedia.org/wiki/Bodoni)
- Overused serif alternatives commonly suggested: Bodoni Moda (sharper, fashion), Libre Caslon Display, DM Serif Display, Abril Fatface (heavy); Fraunces is often proposed as the "less default" choice, but by 2026 it is itself on the tell lists. — [Made Good Designs: Playfair alternatives](https://madegooddesigns.com/playfair-display-alternatives/); compare [Impeccable PR #129](https://github.com/pbakaus/impeccable/pull/129)

### Inferences (recommendations, not sourced; verify each family on fontsource.org before use)

**A. A per-client "art direction derivation" step (replaces picking a style).** For each client, write down before any code:
1. Three physical things from the business's world (materials, objects, signage, documents). Examples: a reformer's steel springs and leather straps; the cotto floor and the hand-painted *ceramica* house number of an agriturismo; the printed *libretto* of a wedding mass; a renovation firm's *cartello di cantiere* and technical drawings.
2. Place and period: the street, the building's era (Milan Liberty, 1950s *palazzina*, a Lombard *cascina*, a Langhe farmhouse), and local lettering (shop signs, enamel street signs, cemetery/monument inscriptions, market price boards).
3. Colours **sampled from the client's own photos** (3 base + 1 accent), named after the thing they come from ("ferro", "cotto", "salvia del giardino") so the token file itself documents the derivation.
4. One signature element taken from that world (see D).
5. A "rejection list": the model writes its first-choice font, palette and layout, then discards them (anti-attractor).

**B. Type-pairing directions beyond the usual suspects** (all OFL on Google Fonts/Fontsource; avoid Inter, Geist, Space Grotesk, Instrument Serif, Fraunces, Playfair, Cormorant, Newsreader, DM Sans/Serif as *defaults*):
- Grotesques with character: Familjen Grotesk, Schibsted Grotesk, Hanken Grotesk, Instrument Sans (keep away from Instrument Serif), Host Grotesk, Funnel Sans/Display, Archivo (has a width axis, so condensed headings and normal text come from one family), Chivo, Work Sans, Public Sans.
- Condensed / poster / signage: Big Shoulders Display, Barlow Condensed, Sofia Sans Extra Condensed, Antonio, Oswald, League Gothic, Fjalla One, Saira Condensed. Good for timetables, prices and cantiere-style signage.
- Slab serifs (workshop, rural, bold): Zilla Slab, Bitter, Aleo, Rokkitt, Arvo, Podkova, Alfa Slab One (display only).
- Text serifs that are not the usual ones: Literata, Source Serif 4, Spectral, Alegreya, Petrona, Besley, Gelasio, Libre Caslon Text, Cardo (Aldine/Venetian, Bembo-inspired, fits Italian Renaissance references), EB Garamond (with real small caps and old-style figures).
- Italian-heritage: Bodoni Moda / Libre Bodoni (Parma, wedding and fashion, but set upright with real hierarchy, *not* one italic word), Titillium Web (Urbino, technical and civic, good for renovation firms).
- Humanist sans for readable body: Alegreya Sans, Fira Sans, Source Sans 3, Atkinson Hyperlegible, Sofia Sans.
- Monospace with a real reason (price lists, technical specs, timetables, not decorative micro-labels): IBM Plex Mono, Martian Mono, Sometype Mono, Courier Prime (typewriter documents), Spline Sans Mono.
- Display with period flavour (one element only): Limelight, Poiret One, Federo, Italiana (Deco), Tenor Sans / Marcellus (inscriptional; avoid Cinzel, which is the wedding cliché), Syne, Unbounded, Bagel Fat One.
- Pairing strategies: (a) single superfamily with width/weight contrast (Archivo, Sofia Sans); (b) slab + grotesque; (c) condensed display + humanist text; (d) Didone display used *upright* + plain grotesque; (e) one family only, with hierarchy from size and weight alone. Use italics for their real job (titles of works, foreign words, emphasis in running text), never as a decorative accent word in the hero.

**C. Layout archetypes to rotate deliberately** (assign one per client from the derivation, never the default hero → 3 cards → stats → testimonials → CTA):
- *Index/list* (a timetable or menu as the hero; ideal for pilates: the weekly class grid *is* the page).
- *Poster* (one huge typographic statement plus one photo; renovation firm, event venue).
- *Full-bleed photographic narrative* (B&B/agriturismo: rooms, breakfast, landscape in sequence, sparse text).
- *Editorial single column* (long-form story of a family venue; one column, generous measure).
- *Catalog / before-after* (renovation projects as a numbered catalogue *only* if numbers are real project IDs or addresses).
- *Split screen* (photo fixed on one side, scrolling content on the other).
- *Asymmetric / grid-breaking* (offset images, overlapping captions) for venues with a strong architectural character.
- *Document/artefact* (the page laid out like the business's own object: an invitation, a *menu del giorno*, a *preventivo*, a *registro degli ospiti*).

**D. Signature element: one per site, from the business's world.** Examples: pilates, spring/coil line drawing as the section divider, or the class timetable in a condensed face; agriturismo, a hand-painted-tile pattern band, or the farm's map drawn as a simple line; wedding venue, an "invitation card" hero with Bodoni and letterpress-style spacing; renovation firm, a *cartello di cantiere*-style info panel (project, address, dates) with Titillium/Archivo and a real material colour.

**E. Colour strategies.** Sample from the client's photography and the place (stone, plaster, cotto, ironwork, vineyard, lake light); one dominant colour plus a sharp accent rather than an even pastel set; avoid the named tell hexes (#F4F1EA-ish cream + #D97757 clay, sage-on-cream, teal-on-cream, near-black + acid green, indigo/purple); dark mode only if the brief calls for it.

**F. Constraints as a generator.** Give each project 2-3 hard constraints from the derivation, e.g. "no rounded corners, because the brand is ironwork", "only two colours, as on the client's van", "all headings in one condensed weight", "no cards at all", "no eyebrow labels; section names go in the heading". These push the model off its centre more reliably than adjectives ("elegant", "modern").

## 4. Checklists and prompts practitioners use to steer LLMs away from defaults

### Takeaway
The tools in use are (1) explicit avoid-lists with hex codes and font names (Anthropic's current skill, OpenAI's frontend guide, avoid-ai-design); (2) **automated detectors/linters** that scan the rendered DOM (Impeccable `detect`, about 62 rules; avoid-ai-design scanner; Hallmark; slop-detect); (3) procedural prompts (write tokens and a wireframe first, enumerate and reject reflex defaults, screenshot critique, remove one accessory). Bans alone shift the model to the next default, so lists must be paired with subject-derived seeds.

### Inferences: a studio checklist distilled from the sources (for `/design-brief` and `/site-qa`)
Before design:
1. Name the subject's world: 3 materials/objects, the place, the period, local lettering. Collect 6-10 references (client photos, signage, printed material).
2. Model lists its reflex font, palette and layout, then discards them.
3. Write the tokens: 4-6 named colours sampled from the photos; 1-2 families with roles; one layout archetype + ASCII wireframe; one signature element; 2-3 hard constraints.
4. Check against the previous 3 studio sites: no shared display face, palette family or archetype.
Before delivery (fail if 3+ are present, per the combination principle):
- Italic or coloured single accent word in a headline · eyebrow above more than one heading · tracked ALL-CAPS labels · `01/02/03` on non-sequences · `A · B · C` meta strings · `→` on every link · cream + terracotta/sage/teal · purple/indigo gradient · identical rounded cards with the same shadow · icon tile above each card · centred hero with two buttons · stats row or "N+ clienti" without a real source · five-star rows / placeholder testimonials · same fade-up on every section · Inter/Geist/Space Grotesk/Instrument Serif/Fraunces/Playfair/Cormorant as default faces · copy with "Non solo X, ma Y", reflexive triplets, poetic three-word taglines, "eleva / esperienza unica / a 360 gradi / su misura / immergiti".
- Run an automated detector (Impeccable `detect` or avoid-ai-design scanner) on the built `dist/` pages.
